# 棋赛编排裁定台

面向业余棋类赛事的编排与裁定工具（React + TypeScript + Vite，纯前端，localStorage 持久化）。

## 功能

- **报名**：录入选手与组别，支持批量导入；开赛前可移除，开赛后可标记临时退赛/恢复参赛
- **瑞士制编排**：按胜场 → 对手分（Buchholz）→ 累进分排序配对，回溯算法优先避开重赛；奇数人数自动轮空（优先给未轮空过的低分选手）
- **裁定台**：裁判甲/乙各自报分，两人一致自动确认；**报分冲突时保留双方记录并提示裁判长裁定，绝不静默覆盖**；裁判更正本人报分后若两份最新报分一致，冲突自动解除；裁判长裁定后普通报分锁定（撤销后重新开放）
- **异常处理**：报分倒计时，超时未报在生成下一轮时自动判双负（不卡死）；弃权/双负场次可安排补赛替代计分；本轮无报分时可整体重排或两台改配
- **联动重排**：较早轮次结果被改判、撤销或补赛替代、选手退赛时，尚未开赛的最新一轮按最新排名自动重新配对——原对阵保留在裁定链与快照中，可恢复，历史不被改写
- **排名**：积分 → 对手分 → 累进分即时重算，任何报分/裁定/补赛改动都会即时反映
- **历史与恢复**：事件溯源存储（活动链 + 回退分支存档）。在回退点上继续操作时，被取代的事件移入分支记录只读保存、不会复活；支持逐步撤销/重做、任意历史步恢复、命名快照（每轮开赛前自动快照）——**恢复只切换活动链，原始记录永不覆盖**，刷新页面后全部保留
- **页面内确认**：裁定、恢复、退赛等所有确认与理由录入均在页面内对话框完成，不依赖浏览器弹窗
- **导出**：一键导出排名与各轮对阵的 Markdown 赛果

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 构建
```

## 结构

- `src/engine.ts` — 纯函数赛事引擎：事件、reducer、瑞士制配对、排名、冲突/裁定、自动重排判断（`maybeRepair`）
- `src/doc.ts` — 文档模型：活动事件链 + head 指针 + 回退分支存档 + 快照链，含旧版数据迁移
- `src/App.tsx` — 界面：报名面板、对阵表、裁定链、快照恢复、页面内对话框
