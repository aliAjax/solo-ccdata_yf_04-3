# 棋赛编排裁定台

面向业余棋类赛事的编排与裁定工具（React + TypeScript + Vite，纯前端，localStorage 持久化）。

## 功能

- **报名**：录入选手与组别，支持批量导入；开赛前可移除，开赛后可标记临时退赛/恢复参赛
- **瑞士制编排**：按胜场 → 对手分（Buchholz）→ 累进分排序配对，回溯算法优先避开重赛；奇数人数自动轮空（优先给未轮空过的低分选手）
- **裁定台**：裁判甲/乙各自报分，两人一致自动确认；**报分冲突时保留双方记录并提示裁判长裁定，绝不静默覆盖**；裁判长可直裁、撤销结果重报
- **异常处理**：报分倒计时，超时未报在生成下一轮时自动判双负（不卡死）；弃权/双负场次可安排补赛替代计分；本轮无报分时可整体重排或两台改配
- **排名**：积分 → 对手分 → 累进分即时重算，任何改动（报分、裁定、补赛、退赛）立即反映
- **历史与恢复**：事件溯源存储，所有操作进入裁定链；支持逐步撤销/重做、任意历史步恢复、命名快照（每轮开赛前自动快照）——**恢复只移动进度指针，原始记录永不覆盖**，刷新页面后全部保留
- **导出**：一键导出排名与各轮对阵的 Markdown 赛果

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 构建
```

## 结构

- `src/engine.ts` — 纯函数赛事引擎：事件、reducer、瑞士制配对、排名计算（可独立测试）
- `src/App.tsx` — 界面：报名面板、对阵表、裁定链、快照恢复
